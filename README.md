# 🎮 Каталог за компютърни игри (Задание No4 - Екип 4)

Уеб платформа, предоставяща подробна информация, каталогизация и оценки за компютърни игри.

## 📝 Описание на заданието
Проектът покрива всички изисквания на Задание No4:
* **Функционални:** Всяка игра съдържа заглавие, студио, година, упътване, рейтинг и изображение. Реализирана е търсачка по име, както и филтриране по производител и минимален рейтинг.
* **Нефункционални:** Напълно адаптивен (Mobile-First) дизайн чрез CSS Grid. Оптимизирано зареждане на изображенията чрез lazy loading (`loading="lazy"`).

## 🛠 Технологичен стек (KISS Методология)
* **База данни:** MySQL 8.0 (в Docker контейнер)
* **Backend:** Node.js + Express + `mysql2`
* **Frontend:** Vanilla JavaScript, HTML5, CSS3
* **Инфраструктура:** Docker Compose + Adminer (за управление на БД)

# ⚙️ Backend & Database - Задачи и Документация

Този файл описва работата по сървърната част и базата данни.

## 🗄️ Структура на Базата Данни
Таблица `games`:
* `id` (INT, Primary Key, Auto Increment)
* `title` (VARCHAR)
* `studio` (VARCHAR)
* `year` (INT)
* `guide` (TEXT)
* `rating` (DECIMAL)
* `image_url` (VARCHAR)

## 🔌 API Endpoints (REST)

### 1. Вземане на всички игри (с опция за търсене и филтриране)
* **URL:** `GET /api/games`
* **Query параметри (по избор):**
  * `?search=име` (Търсене по заглавие чрез `LIKE`)
  * `?studio=име` (Филтър по точно име на студио)
  * `?minRating=число` (Филтър за минимален рейтинг)
* **Пример:** `GET /api/games?search=witcher&minRating=9.0`
* **Отговор:** JSON масив с обекти.
