# 🎨 Frontend & UX - Задачи и Документация

Този файл описва работата по потребителския интерфейс.

## 📁 Файлове
* `index.html` – Структура на страницата (хедър, филтри, контейнер за игри).
* `style.css` – Mobile-First дизайн. Използва CSS Grid за подредба на картите.
* `script.js` – Логика за извличане на данни и рендериране.

## ⚡ Оптимизации
1. **Debounce:** Търсачката изчаква 300ms след спиране на писането, преди да направи заявка към сървъра (намалява натоварването).
2. **Lazy Loading:** Изображенията се зареждат само когато влязат в екрана (`loading="lazy"`).
3. **Адаптивност:** Използван е `grid-template-columns: repeat(auto-fill, minmax(260px, 1fr))`, което автоматично подрежда картите в редица или колона според размера на екрана.

## 🛠 Задачи за Frontend разработчика:
1. Поддръжка на UI компонентите и Fetch заявките.
2. *(Бонус)* Създаване на модален прозорец (pop-up), който се отваря при клик върху играта и показва детайлна информация.
3. *(Бонус)* Добавяне на падащо меню за сортиране (по рейтинг / по година).
4. Тестване на responsive дизайна през Developer Tools (симулация на мобилни устройства).
